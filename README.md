# Scripts-modularizados-ABML
Creación de shell scripts modularizados, que permitan ABML de usuarios y grupos
del servidor, respaldo manual de datos a definir.

Aun falta el script para respaldar los datos (backup) en un disco desmotando
  la idea para el backup es tener un disco desmontado, que el script lo monte, 
  guardar la infomracion y desmontarlo para mantenerlo seguro
